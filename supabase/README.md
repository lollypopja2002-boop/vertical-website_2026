# 공용 방명록 연결

1. https://supabase.com/dashboard 에서 본인 계정으로 프로젝트를 생성합니다.
2. SQL Editor에서 guestbook.sql 전체를 실행합니다.
3. Authentication 설정에서 Anonymous Sign-Ins를 활성화합니다.
4. 프로젝트 URL과 publishable key(또는 기존 anon 공개 키)를 java/guestbook-config.js에 입력합니다.
   service_role, sb_secret 키나 데이터베이스 비밀번호를 넣으면 안 됩니다.
5. GitHub에 사이트 파일을 올립니다.

서로 다른 브라우저 두 개에서 방명록을 열고 도장을 찍어 서로 표시되는지 확인합니다.
공용 저장이 성공하면 안내 문구가 ‘다른 기기의 방문 기록과 함께 저장되어요。’로 바뀝니다.
15초마다 새 기록을 읽고、온라인 복귀와 탭 재방문 시에도 동기화합니다.
기존 로컬 도장은 그 기록이 있는 기기에서 방문해야 자동으로 업로드됩니다.
기존 기록이 http://localhost 등 다른 주소에 남아 있다면 먼저 그 주소에서 별도 내보내기가 필요합니다.

삭제는 작성한 브라우저의 익명 사용자에게만 허용됩니다. 브라우저 데이터를 지우면 삭제 권한을 잃을 수 있습니다.
프로젝트 연결 전에는 기존의 브라우저별 저장 방식을 유지합니다.
실서비스 연결 후에는 대시보드에서 이용량과 익명 가입 제한을 확인하세요.
