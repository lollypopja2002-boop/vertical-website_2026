06세로쓰기 웹 CSS 구현

《CSS Vertical Writing Layout》

페이지 소개

CSS는 웹페이지의 글자、 여백、 크기、 정렬、 배치 등을 지정하는 스타일 언어이다。 CSS Writing Modes는 가로쓰기와 세로쓰기 등 서로 다른 문자 배열 방향을 지원한다。 이 페이지에서는 세로쓰기 웹 구현에 필요한 CSS 속성을 기능별로 구분하고、 각 속성의 적용 방법과 실제 화면에서 나타나는 차이를 살펴본다。

01。쓰기 방향 설정

Writing Mode

writing-mode는 텍스트의 줄이 진행하는 방향과 줄이 쌓이는 방향을 지정하는 CSS 속성이다。 horizontal-tb는 가로 방향으로 글자를 배열하고 줄을 위에서 아래로 쌓는다。 vertical-rl은 글자를 위에서 아래로 배열하고 줄을 오른쪽에서 왼쪽으로 쌓는다。 vertical-lr은 글자를 위에서 아래로 배열하되 줄을 왼쪽에서 오른쪽으로 쌓는다。 전통적인 한글 우종서 세로쓰기에는 vertical-rl을 사용할 수 있다。

02。문자 방향 및 회전

Text Orientation

text-orientation은 세로쓰기 환경에서 글자가 표시되는 방향을 지정한다。 mixed는 문자 종류에 따라 세워진 형태 또는 회전된 형태로 표시하며、 upright는 문자를 세워 표시한다。 text-combine-upright는 여러 문자를 세로줄 안의 하나의 가로 방향 묶음으로 표시할 때 사용한다。 영문、 숫자、 기호가 포함된 세로쓰기 문장을 구성할 때 활용할 수 있다。

03。글꼴 및 문자 간격

Font and Character Spacing

font-family는 사용할 글꼴을 지정하고 font-size는 글자의 크기를 설정한다。 letter-spacing은 글자 사이의 간격을 조절하며、 word-spacing은 단어 사이 공백의 간격을 조절한다。 세로쓰기에서는 글자가 위에서 아래로 배열되므로 letter-spacing의 변화가 세로 방향의 글자 간격에 반영된다。 글꼴의 형태와 크기、 간격 설정에 따라 세로줄의 길이와 문장의 밀도가 달라진다。

04。행간 및 줄 높이

Line Height

line-height는 글줄의 높이를 설정하는 속성이다。 가로쓰기에서는 주로 위아래로 쌓이는 줄 사이의 공간에 영향을 주지만、 세로쓰기에서는 좌우로 나란히 놓이는 줄 사이의 공간에 영향을 준다。 글자 크기와 line-height를 함께 조절하여 세로줄의 간격을 설정할 수 있다。

05。줄바꿈 및 단어 분리

Line Breaking

word-break는 줄 끝에서 단어와 글자를 나누는 방식을 지정한다。 overflow-wrap은 긴 문자열이 지정된 영역을 넘칠 때 줄바꿈을 허용하는 방식을 설정한다。 white-space는 공백과 줄바꿈 문자의 처리 방식을 제어하며、 line-break는 언어별 줄바꿈 규칙의 엄격도를 지정한다。 세로쓰기에서도 이러한 속성을 이용하여 제한된 줄 길이 안에 문장을 배치할 수 있다。

06。텍스트 정렬 및 들여쓰기

Text Alignment

text-align은 줄 안에서 텍스트를 정렬하는 속성이다。 세로쓰기에서는 start와 end가 쓰기 방향에 따라 해석되므로 일반적인 우종서 세로쓰기에서 start는 줄의 위쪽에 해당한다。 text-indent는 문단 첫 줄의 시작 부분에 들여쓰기를 적용한다。 text-align-last는 문단의 마지막 줄 또는 강제 줄바꿈 직전 줄의 정렬 방식을 지정한다。

07。문장부호 및 기호 처리

Punctuation and Symbols

세로쓰기에서는 문자와 기호의 종류에 따라 표시 방향이 달라질 수 있다。 괄호와 일부 문장부호는 세로쓰기용 글리프를 사용하거나 방향이 조정될 수 있으며、 실제 표시 결과는 글꼴과 브라우저의 문자 처리 방식에 영향을 받는다。 text-orientation과 font-feature-settings 등을 활용하여 표시 방식을 검토할 수 있다。 단、 모든 문장부호의 방향을 하나의 CSS 속성으로 일괄 지정할 수 있는 것은 아니다。

08。논리적 여백 설정

Logical Margin and Padding

margin-inline과 padding-inline은 글이 진행하는 축을 기준으로 바깥쪽 여백과 안쪽 여백을 설정한다。 margin-block과 padding-block은 줄이 쌓이는 축을 기준으로 여백을 설정한다。 세로쓰기에서는 inline 축이 세로 방향이고 block 축이 가로 방향이므로、 물리적 방향을 나타내는 top、 right、 bottom、 left 대신 논리적 속성을 활용하면 쓰기 방향에 대응하는 레이아웃을 구성할 수 있다。

09。테두리 및 요소 크기

Logical Borders and Sizing

inline-size는 글이 진행하는 축의 크기를 지정하고 block-size는 그와 직교하는 축의 크기를 지정한다。 일반적인 가로쓰기에서는 inline-size가 너비에 해당하지만、 세로쓰기에서는 높이에 해당한다。 border-inline과 border-block 역시 쓰기 방향을 기준으로 테두리를 설정한다。 이러한 논리적 속성은 가로쓰기와 세로쓰기 사이에서 요소의 크기와 방향을 관리하는 데 활용된다。

10。Flexbox 레이아웃

Flexible Box Layout

Flexbox는 요소를 한 방향으로 배열하고 정렬하는 CSS 레이아웃 방식이다。 display: flex로 활성화하며、 flex-direction으로 주축의 방향을 지정한다。 row와 column은 요소의 쓰기 방향에 따라 서로 다른 물리적 방향으로 나타날 수 있다。 justify-content는 주축을 기준으로、 align-items는 교차축을 기준으로 요소를 정렬한다。

11。Grid 레이아웃

CSS Grid Layout

CSS Grid는 행과 열을 이용하여 요소를 배치하는 2차원 레이아웃 시스템이다。 display: grid로 활성화하며、 grid-template-columns와 grid-template-rows로 격자 구조를 지정한다。 Grid의 행과 열은 쓰기 방향의 영향을 받으므로 세로쓰기 환경에서는 실제 화면에 나타나는 축의 방향을 확인해야 한다。 grid-auto-flow는 자동 배치되는 요소의 진행 방식을 제어한다。

12。요소 위치 및 정렬

Positioning

position은 요소의 배치 방식을 지정한다。 relative、 absolute、 fixed、 sticky 등의 값을 사용할 수 있다。 inset-inline-start와 inset-inline-end는 글의 진행 방향을 기준으로 위치를 지정하며、 inset-block-start와 inset-block-end는 줄이 쌓이는 방향을 기준으로 위치를 지정한다。 세로쓰기에서는 논리적 위치 속성을 이용하여 제목、 메뉴、 고정 요소 등의 배치를 설정할 수 있다。

13。스크롤 및 오버플로

Overflow and Scrolling

overflow-x와 overflow-y는 요소의 내용이 지정된 영역을 넘칠 때 가로축과 세로축의 처리 방식을 설정한다。 세로쓰기에서는 줄이 오른쪽에서 왼쪽으로 늘어나므로 내용이 가로 방향으로 확장될 수 있다。 overflow-x: auto를 적용하면 필요한 경우 가로 스크롤이 제공된다。 scroll-snap-type은 스크롤 위치가 특정 지점에 맞춰 정렬되도록 설정할 때 사용한다。

14。링크 및 버튼

Links and Buttons

링크와 버튼은 HTML 요소에 CSS를 적용하여 구성한다。 세로쓰기에서는 writing-mode와 text-orientation을 이용하여 버튼 안의 글자 방향을 설정할 수 있다。 padding-inline과 padding-block을 활용하면 글자의 진행 방향에 맞춰 내부 여백을 조정할 수 있다。 버튼의 크기、 정렬、 클릭 영역은 실제 사용 환경을 고려하여 별도로 설정해야 한다。

15。텍스트 입력 및 선택

Text Input and Selection

input과 textarea에도 writing-mode를 적용할 수 있지만、 세로쓰기 입력 동작과 지원 범위는 브라우저 및 운영체제에 따라 달라질 수 있다。 caret-color는 텍스트 입력 커서의 색상을 지정하고 user-select는 사용자의 텍스트 선택 가능 여부를 제어한다。 입력 커서의 이동 방향이나 드래그 동작은 CSS만으로 완전히 제어할 수 없으며 브라우저의 기본 동작을 함께 고려해야 한다。

16。반응형 레이아웃

Responsive Layout

미디어 쿼리는 화면 크기와 사용자 환경에 따라 서로 다른 스타일을 적용하는 기능이다。 @media를 이용하여 화면 너비나 높이에 따른 배치 변화를 지정할 수 있다。 min()、 max()、 clamp() 등의 CSS 함수를 이용하면 글자 크기와 요소 크기를 유동적으로 설정할 수 있다。 세로쓰기 웹에서는 화면 높이에 따라 한 줄에 들어가는 글자 수가 달라질 수 있으므로 가로와 세로 크기를 함께 고려해야 한다。

17。전환 및 애니메이션

Transitions and Animations

transition은 CSS 속성값이 변할 때 전환 효과를 설정한다。 transform은 요소의 이동、 회전、 크기 변경 등에 사용되며、 animation과 @keyframes를 이용하면 시간에 따라 반복되거나 단계적으로 변하는 움직임을 만들 수 있다。 세로쓰기 웹에서는 메뉴의 등장 방향、 요소의 이동、 문자 회전 등의 시각적 효과에 활용할 수 있다。

18。세로쓰기 CSS 통합 적용

Vertical Writing Implementation

세로쓰기 웹은 writing-mode 하나만으로 완성되지 않는다。 문자 방향과 글자 간격、 줄바꿈、 정렬、 여백、 요소 크기、 레이아웃、 스크롤 등 여러 CSS 속성을 함께 설정해야 한다。 각 속성의 동작을 확인하고 조합하면 세로쓰기의 읽기 방향에 맞는 웹페이지를 구성할 수 있다。
